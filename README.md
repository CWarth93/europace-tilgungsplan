# Europace Tilgungsplan

Web application for creating an annuity-loan repayment schedule. It consists of an Angular frontend and an Express REST API, both written in TypeScript.

## Structure

- `frontend/` – Angular application
- `backend/` – Express API

## Local development

Run the frontend with `npm start` in `frontend/`, and the API with `npm run dev` in `backend/`.

The calculation and interactive interface will be added in the next implementation step.
